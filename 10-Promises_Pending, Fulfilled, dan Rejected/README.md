Rangkuman materi Promise
- resolve() — menandai operasi berhasil.
- reject() — menandai operasi gagal.
- .then() — menangani hasil berhasil.
- .catch() — menangani kegagalan.
- setTimeout() — menyimulasikan proses yang membutuhkan waktu.
- return — meneruskan nilai ke .then() berikutnya.
- throw new Error() — membuat alur gagal dan mengarah ke .catch().
- export dan import — menggunakan Promise dari file lain.
